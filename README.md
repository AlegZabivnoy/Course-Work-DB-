# Сервісний центр Apple / Samsung

Backend-застосунок для сервісного центру, що ремонтує смартфони Apple та Samsung і продає запчастини.

Система обліковує клієнтів і їхні пристрої, ремонтні замовлення, роботу майстрів, склад запчастин та продажі в магазині.

Курсова робота з дисципліни «Бази даних».

## Встановлення та запуск

### 1. Клонувати репозиторій

```bash
git clone https://github.com/AlegZabivnoy/Course-Work-DB-
cd Course-Work-DB-
```

### 2. Створити файл .env

Скопіювати шаблон `.env.example` у `.env`.

Відкрити `.env` і замінити пароль у рядку `DATABASE_URL` на власний (між `:` та `@localhost`).

> Файл `.env` не потрапляє в Git — кожен учасник створює його у себе.

### 3. Встановити залежності

```bash
npm install
```

### 4. Запустити базу даних

Переконатися, що Docker Desktop запущений, і виконати:

```bash
docker compose up -d
```

Перевірити, що контейнер працює (статус `running`):

```bash
docker compose ps
```

### 5. Згенерувати Prisma Client

```bash
npx prisma generate
```

### 6. Застосувати міграції

> Буде додано після створення першої міграції.

### 7. Запустити застосунок

```bash
npm run dev
```

### 8. Перевірити роботу

Відкрити в браузері http://localhost:3000/health.

Якщо база даних недоступна, сервер відповість кодом помилки.

## Команди

| Команда | Що робить |
|---|---|
| `npm run dev` | Запуск з автоперезавантаженням при змінах коду |
| `npm start` | Звичайний запуск |
| `npx prisma generate` | Генерація Prisma Client зі схеми |
| `docker compose up -d` | Запуск бази даних у фоні |
| `docker compose down` | Зупинка бази (дані зберігаються) |
| `docker compose down -v` | Зупинка з видаленням даних у Docker volumes |

## Можливі проблеми

| Проблема | Рішення |
|---|---|
| Не знайдено `.env` | Файл не створено або він лежить не в корені проєкту — див. крок 2 |
| Docker не підключається | Docker Desktop не запущений або ще стартує |
| Не знайдено `package.json` | Перевірити папку проєкту командою `pwd` |
| Не знайдено Prisma Client | Виконати `npx prisma generate` |
| Сервер повертає помилку підключення до БД | Перевірити, чи запущена база даних і чи правильний `DATABASE_URL` |
